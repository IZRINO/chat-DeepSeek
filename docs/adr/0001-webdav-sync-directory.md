# 三端通过 WebDAV 目录双向同步会话

网页、Windows 和 Android 使用同一份目录格式。每个会话独立保存完整消息树，附件原件单独保存，同一原件可被多条消息引用。现有 ZIP 归档只包含图片原件，还会省略部分续聊状态，因此同步格式直接以本地会话为依据。

首次连接合并本机和目录中已有的会话。后续每轮对话落盘后只传发生变化的会话和新增原件。新设备可以从该目录取得完整历史，已有设备可以保留各自离线期间的新增内容。对于历史上只有文件信息的附件，保留已有信息。

设备使用者能在网盘中直接阅读会话文件、打开附件原件。有目录读取权限的人也能查看这些内容。聊天 Key、独立搜索 Key、WebDAV 凭据及设备设置均由各端本地管理。
